# PSO_ANN_Project

The main.py file executes one PSO-trained ANN model on the Concrete Compressive Strength data set. To run the complete experimental study, run run_experiments.py, which will test a variety of ANN architectures and PSO hyperparameters automatically , it will also run PSO ten times each, and the average values will be stored in experiments/results.csv.
You will need Python 3, NumPy and pandas for the project.
This can be downloaded by running the command:
pip install numpy
pip install pandas
